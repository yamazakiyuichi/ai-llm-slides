OVERVIEW
LLMの定義
大量のテキストデータから学習し、人間のように自然な文章を理解・生成するAIモデル
L
Large - 大規模
数十億〜兆単位のパラメータと膨大なデータ量
L
Language - 言語
テキスト、コード、翻訳などに特化
M
Model - モデル
文脈を理解し、次の言葉を予測する深層学習アルゴリズム
創発的能力 (Emergent Abilities)
モデル規模が一定を超えると突然獲得される様々な能力で、これにより生成の質が飛躍的に向上しました。

LEARNING
AIはどうやって
賢くなる?
AIは最初から答えを知っているわけではありません。「予測」して「失敗」して「修正」する。このループを高速で繰り返しています。
1
予測する
現在の a と b で計算してみる
y = ax + b
▼
2
ズレを確認
実際の答え合わせをして誤差を計算する
| 予測 - 正解 |
▼
3
パラメータ修正
ズレが小さくなるように a と b を微調整
この繰り返しが「学習」です
何千回、何億回と繰り返すことで、a（重み）と b（補正）が最適な値になり、予測がより正確になります。

膨大なデータから「予測→失敗→修正」を繰り返すことで、自動的に最適な値が得られます。

学習だけでなく、人間が意図的に補正を加えることで、出力の精度や安全性を調整しています。

CONCLUSION
まとめ
POINT 1
単純計算の集合体
AI（LLM）の本質は y = ax + b の大量の組み合わせです。
POINT 2
経験則と同じ原理
皆さんが普段行っている「経験から判断する」こととAIは本質的に同じです。
POINT 3
圧倒的な処理速度
人間が数秒で行う判断を、AIは何千億回の計算として一瞬で実行します。
AI (LLM)
経験がない領域の判断はできない
未知の事象には過去のデータからの推測しかできない
人間
直感や推論で判断できる
0から1を生み出す創造性や論理的な飛躍が可能

革命的技術：アテンション機能
Multi-Head Self-Attention が現在の生成AIブームを作り出しました。文脈の中での「単語間の関係性（注目度）」を計算し、人間のような自然な理解を可能にしています。
APPENDIX
AI用語でよく聞く言葉
重要キーワード
🏷
トークン
Token
AIが文章を処理する際の最小単位。単語や文字の一部などを指し、AIはこの単位で理解・生成を行う。
✍
プロンプト
Prompt
AIに対する指示や質問のテキスト入力のこと。具体的で明確なほど、精度の高い回答が得られる。
📏
コンテキストウィンドウ
Context Window
AIが一度に記憶・処理できるトークンの上限枠。これを超えると古い情報は忘れられてしまう。
📝
MDファイル
Markdown File
見出し(#)や太字(**)などの書式を記号で記述する軽量テキストファイル。AIとのやり取りでよく利用される。
